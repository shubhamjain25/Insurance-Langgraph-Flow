🏥 Claim Wizard

AI-powered insurance claim document processing built using LangGraph, FastAPI, and Groq. Upload a medical document and the workflow performs OCR, field extraction, confidence scoring, and returns a final PASS / REVIEW / FAIL outcome.

🧠 Workflow

START ↓ input_node ↓ parser_node ├─ APPROVED → processor_node ├─ REJECTED → aggregator_node └─ FAILED → retry (max 2 retries) ↓ aggregator_node ↓ END

📄 Supported Claim Categories

  • CONSULTATION
  • DIAGNOSTIC
  • PHARMACY
  • DENTAL
  • VISION
  • ALTERNATIVE_MEDICINE

📎 Supported Document Categories

  • PRESCRIPTION
  • HOSPITAL_BILL
  • LAB_REPORT
  • DIAGNOSTIC_REPORT
  • DISCHARGE_SUMMARY
  • PHARMACY_BILL

Template documents present inside ./uploads inside the github repository: View Templates Docs

📊 Scoring Signals

  • clarity_score → document legibility & parse quality
  • classification_score → confidence of claim ↔ document match
  • confidence_score → processing confidence in final result

⚙️ Routing Rules

  • Parsed + thresholds passed → APPROVED
  • Parsed but low confidence → REJECTED
  • Parse failure + retries left → Retry parser
  • Retry exhausted → Final aggregation

Claim Wizard is an AI-powered insurance document processing workflow that automates claim validation.

Upload a supported medical document and the system performs OCR extraction, validates document quality, evaluates whether the uploaded document matches the selected claim and document category, applies confidence scoring, and returns a final processing outcome with supporting reasoning.

Built as a stateful LangGraph pipeline with structured routing, retry handling, and consolidated output for insurance claim review workflows.
