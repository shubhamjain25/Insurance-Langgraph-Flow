Architecture

Stateful routing graph

Each document traverses a structured pipeline. The parser extracts and scores the document; the processor reconciles it against user claim data. Failed parses retry up to twice before final aggregation.

input_node
Validates and hydrates the user-submitted form data into a typed DocumentValidator state. Sets status → initiated and passes claim_category + document_category downstream.
parser_node
Calls OCR Space → feeds raw text into Groq with a per-document-category system prompt → validates JSON into a discriminated OCR schema carrying clarity_score and classification_score.
processor_node
Reconciles OCR output against user claim. Applies document-category-aware rules — financial checks only fire on HOSPITAL_BILL and PHARMACY_BILL. Returns a ProcessingResult.
aggregator_node
Terminal consolidation node — reached via any path (approved, rejected, retry-exhausted). Writes final status and prepares the API response payload.

Scoring Model

Two-stage, three-signal evaluation

Two independent LLM calls emit three distinct confidence signals. Each gate must clear before advancing to the next stage.

parser_node → OCR schema
clarity_score
How legible and parseable the uploaded image is. Reflects physical document quality — handwriting, scan resolution, lighting conditions.
Threshold: > 0.4 required to route APPROVED
parser_node → OCR schema
classification_score
Confidence that the document content matches the declared claim_category and document_category. Catches wrong document uploads early.
Threshold: > 0.4 required to route APPROVED
processor_node → ProcessingResult
confidence_score
Overall reconciliation confidence — how strongly OCR-extracted fields (name, date, amount where applicable) match the user-submitted claim data.
≥ 0.75 → PASS   0.5–0.75 → REVIEW   < 0.5 → FAIL
Routing Logic

parser_router decision table

Evaluated after every parser_node execution. count_itr is an Annotated[int, operator.add] reducer — it accumulates across retries without overwriting.

Route Condition Next Node
APPROVED status == parsed_success
AND clarity_score > 0.4
AND classification_score > 0.4		 → processor_node
REJECTED status == parsed_success
BUT either score ≤ 0.4		 → aggregator_node
FAILED status == parsed_failure
AND count_itr < 2		 → parser_node (retry)
RETRY_EXHAUSTED status == parsed_failure
AND count_itr == 2		 → aggregator_node
Technical Design

Key implementation decisions

Architectural choices made to work reliably with open-source LLMs and maintain a clean, extensible pipeline structure.

Schema Design
Discriminated Union OCR schemas
Rather than a single flat OCR schema, each document category has a dedicated Pydantic model with domain-specific fields (PrescriptionOCR, HospitalBillOCR, etc.). Pydantic's discriminated union on doc_type resolves the correct model at validation time. This keeps schemas strict and prevents phantom fields from polluting unrelated document types.
Open-Source LLM Compatibility
Manual JSON parse + match statement
LangChain's with_structured_output is unreliable with smaller open-source models hosted on Groq. Instead, the LLM is prompted to return raw JSON; the response is parsed with json.loads() and routed through a match document_category block that explicitly instantiates the correct Pydantic model. field_validator guards handle None-as-string quirks from the model.
Processor Design
Document-aware reconciliation queries
A single processor prompt caused false FAILs — financial rules fired on PRESCRIPTION documents which carry no total_amount field. The processor now routes to one of six system prompts by document_category: financial rules apply only to HOSPITAL_BILL and PHARMACY_BILL; date logic is also tailored (e.g. discharge summary checks a date window, not an exact match).
Retry Circuit Breaker
Additive count_itr reducer
LangGraph state reducers prevent infinite retry loops without external counters. count_itr: Annotated[int, operator.add] accumulates across every pass through parser_node. The parser_router checks count_itr == 2 to emit RETRY_EXHAUSTED and short-circuit to aggregator_node, guarding against network failures stalling the pipeline indefinitely.
